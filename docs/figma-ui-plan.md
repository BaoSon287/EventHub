# Figma UI Plan

## Screens

- Home page
- Event listing page
- Event detail page
- Login page
- Register page
- Organizer dashboard
- Create event page
- My tickets page
- Admin dashboard

## Style Direction

- Modern interface with a clear event marketplace feel.
- Primary colors: blue and purple.
- Event cards should show title, date/time, location, price, and ticket availability clearly.
- Desktop-first responsive layout, with mobile refinements after the core flows are stable.
- Organizer and admin screens should be dense, readable dashboards rather than marketing pages.

## Key Components

- Top navigation with search and account actions.
- Event card grid.
- Event detail hero with ticket purchase panel.
- Auth forms with validation states.
- Dashboard tables for events, bookings, and users.
- Create event form with date, location, pricing, and ticket inventory fields.
